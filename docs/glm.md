# API Reference

The two main classes in `glum` are [`GeneralizedLinearRegressor`][glum.GeneralizedLinearRegressor] and [`GeneralizedLinearRegressorCV`][glum.GeneralizedLinearRegressorCV]. Most users will use [`fit()`][glum.GeneralizedLinearRegressor.fit] and [`predict()`][glum.GeneralizedLinearRegressor.predict].
